# 0.12.2：遠征內容與觸控控制盤

本版整合 R78–R84 的遊戲、地景與操作改善，PWA 快取版本為 `td-r84-v3`。

## 遊戲內容

- 三套十二波遠征：溪橋守望、裂谷封鎖、熔心封印。每套都有四段敵群編排，第十二波真正清完後才勝利。
- 十二種本局祝福，在第 3、6、9 波後各從三張未持有的牌中選一張，也可略過。
- 三種可選單波契約：加速、援軍、禁法。只有真正清波才領取額外賞金。
- 遠征紀錄與無盡排行榜分開，支援通關、接下一圖、重玩與存檔匯出／匯入。局內加成不變成永久能力。

## 地圖與戰鬥

三張獨立地景共用實際地形／道路／橋面幾何。前線、交火點、尾線各有用途；英雄繞障礙與過橋，完整塔基不落在河、崖、熔岩或禁建區。

保留逐格行走、受擊、死亡與前搖／命中／收招，傷害在命中時發生。新增塔目標優先、剩餘敵人與 Boss 狀態、波間戰報與有成本的補強建議。地景、路線與導航資料有快取，導航採 min-heap。

## 手機與平板

控制盤分成建塔、技能、已建與更多，每頁至多四項，顯示完整名稱、金額與冷卻。寬平板依觸控能力或實際觸控啟用；一般滑鼠桌面保留原操作。

建塔可選建議位、近格安全對齊與四方向微調，明確確認後只付款一次。技能先顯示落點、範圍圈與目標數，再確認施放。轉向、拖曳與多指取消不會誤買或誤發。

已建塔可從清單選取，近點也有命中容錯。操作時可自動暫停規劃；完成／取消後恢復，原先手動暫停則保持。英雄駐守與抽屜交接也有補驗。

## 驗證範圍

公開測試可在乾淨 checkout 執行；沒有私有 R81 快照時，歷史引擎精確比較會明確 SKIP，其餘正式語意守門照跑，不把缺失基線稱為通過。

本機已驗單元、完整 E2E／離線載入、四裝置原生觸控流程、九視口 RWD 及幀時間守門。四裝置為 360×640、390×844、820×1180、1180×820；使用 Chromium 裝置模擬，目標敵人与英雄 fixture 在測試中明示，不是實機手指研究或戰役勝率。

十二組正式引擎遠征模擬與桌機／手機原生十二波配置均完成；普通難度有較高餘裕，嚴酷／煉獄及所有抽卡分布未作全矩陣結論。壓力 fixture 的 18ms p95 守門通過，但最大單幀仍有尖峰，不宣稱零頓挫。

完整歷史截圖、暫存與私人主機路徑留在維護者本機。公開版保留必要來源紀錄、最終素材與精簡驗證摘要：[驗證摘要](releases/0.12.2/validation.json)。
